# 구현 및 검증 기록

## 설계 기준

사용자가 제공한 `RAG-Design` Markdown의 확정 설계를 기준으로 구현했습니다. 문서 내부 제출·발표 안내는 구현 참고 자료이며, 외부 게시나 전송 요청으로 취급하지 않았습니다. 기존 `CLAUDE.md`의 모델·그래프·점수 초안은 확정 설계로 대체했습니다.

## 구현상 선택

- EnsembleRetriever와 같은 weighted reciprocal-rank fusion을 직접 구현했습니다. Dense와 BM25에 동일한 메타데이터 필터를 적용합니다. 두 가중치는 0.5, rank constant는 60입니다.
- 관련 청크가 2개 미만이면 질의별 최대 2회 재검색합니다. 질의 3개 각각 Top-5를 사용합니다.
- 정량 충돌·단위 불일치·인용 원문 불일치를 결측 처리합니다. 정성 채점은 실제 evidence ID만 허용합니다.
- FAISS pickle을 역직렬화하지 않습니다. 기존 평가 인덱스는 보존하고 v2 JSON 메타데이터를 사용합니다.
- 청크 ID는 `doc_id:원본페이지:문서내순번`. 기존 평가셋·결과는 보존하며 v2 평가는 별도 파일을 생성합니다.
- ROI는 설계대로 수치 추정하지 않으며 성장 여력으로 대리 평가합니다.
- PDF는 최소 9pt, 최대 5쪽을 확인합니다. 초과 시 잘라내지 않고 Markdown 보존 후 오류를 반환합니다.
- 합성 데모에서 외부 API·임베딩·추적을 비활성화합니다. 실제 모드에 데모 자동 폴백은 없습니다.

## 검증 범위

- 34개 자동 테스트: 점수/단위/70점 경계, 결측 5개 강제 보류, 선정 출처 검증, 원문 인용 검증, 양산 예정·산업 일반 위험의 오독 차단, 이름 중복, 투자 조기 종료, 전원 보류, 전원 선정 탈락, REVIEW 1회, evidence 재수집 상한, RAG 2회 및 웹 보완, 평가 수 제한, 메타데이터 필터, 원본 페이지 보존, Hit Rate/MRR 계산, 인덱스 재사용·체크섬, 한글 PDF·분량 초과 처리.
- 실제 제공 PDF 4종 청킹 검사.
- 투자·전원 보류·결측·선정 탈락 데모에서 Markdown/PDF 출력.
- PDF 페이지 수 및 한글 렌더링 육안 검사.
- 실제 API 소규모 검증: gpt-4.1-mini 구조화 응답 정상, Tavily 검색 5건 반환 확인.
- 2026-09-30 실제 Qwen 인덱스(125청크), 세 모델 Dense/Hybrid 20문항 평가 및 실데이터 그래프 완료. 09:04 실데이터 실행은 모빌린트 73점·근거 7/13·결측 6/13으로 보류했고, 비교 기업 4곳을 출처로 검증했다. 이후 보고서 검토에서 ‘양산 예정’을 양산 완료로 읽은 근거와 산업 일반 리스크를 회사별 리스크로 읽은 근거를 발견했다. 검증 규칙 수정 후 저장된 실행 근거를 재판정한 결과는 69점·근거 5/13·결측 8/13·보류이며, `outputs/report_recheck/20260930-corrected-090940/`에 3쪽 교정 보고서와 거절 사유를 보존했다. 원래 실행의 `run.json`/`quality.json`과 교정 실행을 구별해 확인한다. 기존 Dense 평가를 새로운 Hybrid 실측으로 재사용하지 않는다.
