# 평가기준별 산출물 적합성 점검 및 보완

2026-09-30. 과제 개발 평가표(100점)와 제공된 확정 설계 `RAG-Design.md`를 기준으로 점검했다. 아래 배점은 과제의 배점이며, 자체 점수를 실제 채점 결과처럼 부여하지 않는다.

## 변경 전 발견 사항

기존 마지막 실데이터 실행은 모빌린트 60점·보류, 13/13 지표 결측이었다. 저장된 23개 근거 중 19개는 채점용이 아닌 요약 context였다. 기술·시장·경쟁 분석이 기업 소개를 반복했고, 단일 라운드 700억과 과거 누적 300억이 동일 지표로 들어갔다. 합성 테스트 18개 통과는 실제 정보 추출의 정확성을 검증하지 못했다.

추가 실데이터 진단에서 확인한 원인:

- 지표 키가 영문 코드 대신 한글 설명으로 출력됨.
- 단일 출처 ID 대신 `S1,S2`를 반환하거나 여러 문장을 이어 붙인 인용문을 생성함.
- 개발 단계 문자열 대신 루브릭 점수 5/3을 반환함. 계약에서 단계→점수 사전을 전달한 것이 혼동 요인이었다.
- 자료에 존재하는 정보도 인용 검증에서 탈락했으나 탈락 원인을 저장하지 않아 진단할 수 없었음.
- 이전 기업 프로필·선정 사유를 후속 프롬프트에 통째로 제공해 분석 영역의 구분이 약했음.

## 설계와 구현의 차이 및 해석

- **페이지 수:** 원본 준비 결과 10+12+23+55=100쪽이다. 설계의 102쪽은 계획값이며 구현의 페이지 삭제를 의미하지 않는다. 연구 보고서 원본 27~81쪽 인용 기준은 유지한다.
- **Embedding:** Qwen3-0.6B를 유지한다. 현재 20문항 Hybrid에서 Qwen은 Hit@3=1.0, BGE-M3는 MRR@5=.8625로 서로 강점이 다르다. 기존 설계의 Dense 결과와 새로운 v2 결과를 혼합하지 않는다.
- **Hybrid:** 가중 RRF(0.5/0.5, 상수 60)를 직접 구현해 동일 필터를 Dense/BM25에 적용한다.
- **추출:** LLM에 원문 구간 ID를 선택하게 하고 실제 인용문과 source_id는 코드가 복원한다. 스키마에서 영역별 필드·값 타입·단계 enum을 제한한다. 정량 점수와 최종 결정은 여전히 코드만 수행한다.
- **정량 해석:** 원문 숫자와 단위 변환을 검증한다. 단일 라운드를 누적액으로 대체하지 않는다. 관측일이 명시된 동일 지표의 과거/현재 차이는 최신 관측을 사용하며, 날짜가 불분명하거나 시장 범위·기간이 다르면 결측으로 남긴다.
- **실데이터 재판정:** 09:04 라이브 실행에서 73점·근거 7/13이 나왔지만 PDF 대조에서 양산 예정과 산업 일반 위험을 실제 회사 근거로 오독한 2개 지표를 확인했다. 해당 검증을 보강하고 저장된 원문/판단으로 재판정한 최종 검토 결과는 69점·근거 5/13·결측 8/13·보류다. 교정 PDF와 거절 이유는 `outputs/report_recheck/20260930-corrected-090940/`에 보존했다. 이는 새로운 전체 API 실행이 아닌 오프라인 근거 재검증이다.
- **실행 결과:** `outputs/live/<시각-ID>/`에 저장한다. `latest.json`은 최근 성공한 실행을 가리킨다. 과거 실행의 파일은 덮어쓰지 않는다.
- **환경 공유:** 사용자 요청에 따라 pyproject/uv.lock/.python-version은 로컬 스캐폴딩으로 Git 제외. 고정 requirements와 설치 스크립트를 공유한다. `config/env.sample`만 비밀값 없는 예외이다.

## 남는 한계

- 원문 구간과 숫자 검증이 통과해도 LLM의 의미 해석을 완전히 보증하지는 않는다. 공급사 주장과 독립 검증을 구분해 읽어야 한다.
- 기술 인력 수·실제 계약 수·실현 매출 등 공개되지 않은 사실은 결측으로 유지한다. 높은 점수를 만들기 위한 추정이나 결측 기준 완화는 하지 않는다.
- 시장 범위·기간이 상충하는 수치는 보수적으로 결측 처리한다. 실제 기업 TAM에 산업 전체 통계를 대입하지 않는다.
- 소규모 질문 20개로 모델의 보편적 우열을 단정하지 않는다. Hit@5=100%는 최종 투자 보고서 정확도 100%를 의미하지 않는다.
- 제출물의 사실성은 원문과 함께 검토해야 하며, 자동 품질 결과는 실행·근거 연결·형식 확인 범위이다.
- 교정 보고서의 외부 웹 인용 4건은 제공된 검색 메타데이터에 발행일이 없어 `발행일 미상`으로 표기했다. 날짜를 임의로 추정하지 않았다.
